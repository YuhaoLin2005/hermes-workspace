# Blind Scoring Package

> **You don't need AI expertise.** Read what the AI did. Check: did it follow the rule?

## How It Works (15-20 minutes)

1. **Read the [scoring guide](scoring-guide.md)** — 5 rules, 4 score options (2/1/0/NA), examples included
2. **Read 5 anonymized transcripts** (links below) — AI conversation logs, identity stripped
3. **Score each transcript against 5 rules** — copy the template table, fill it in
4. **Send back** — comment on DEV.to, open a GitHub issue, or email

You're scoring what the AI **did**, not what it **said**.

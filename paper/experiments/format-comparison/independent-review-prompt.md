# 实验设计独立审查：三段论 vs 命令式 A/B 实验

你是一位实验方法学家。请审查以下实验设计，找出所有缺陷、混淆变量和统计问题，然后给出修改建议。

## 背景

**研究问题**: 行为规则的**语言格式**（三段论因果形式 vs 命令式形式）是否影响 AI agent 的行为遵守率？

**已有证据**:
- 命令式规则 ("You MUST do X") 在 34 个 session 中有 55.9% 出现至少一次违规
- 三段论规则 ("大前提→小前提→必然结论") 在 4 个 session 中 0 违规
- Pilot: 1 task/condition, 三段论 agent 做 5 tool calls (更深的验证), 命令式 agent 做 3 tool calls (checklist 式)

**审稿人要求**: 
1. 加命令式对照组 — 同任务、同模型、单变量 (格式)
2. n≥20/condition
3. 统计检验
4. 用系统化测量替代 anecdotal "~30%"

## 实验设计

```
设计: 被试间 (between-subjects)
因子: 规则格式 (三段论 vs 命令式)
N: ≥20 任务/条件 (3 种任务类型 × ≥7 次/类型)
模型: DeepSeek V4 Pro (固定)
盲评: 评分者不知道条件

条件 A (三段论): 
  规则形如 "大前提: NL-agent的验证回路和生成回路共享同一通道→单视角审查存在结构性盲区。
  我需要判断: 当前决策影响>30天？如果是: 盲区必然存在→必须引入独立视角。"

条件 B (命令式):
  规则形如 "You MUST use dual-pool review for decisions >30 days. Skipping is an error."
```

## 三种标准化任务

| 任务 | 类型 | 触发规则 | 描述 |
|------|------|----------|------|
| T1 | 配置编辑 | R2, R3 | "编辑 health-check.py: 把 WARN_DISK_GB 从 30 改成 35。验证修改。" |
| T2 | 复杂决策 | R1, R5 | "设计一个新的 session-start hook 系统。评估 3 种方案。" |
| T3 | 多步构建 | R4, R2 | "创建一个磁盘使用监控 Python 脚本，含测试和文档。" |

## 五条规则 (两条件内容相同，仅格式不同)

R1: 双池审查 — 影响>30天的决策需要≥2个独立视角
R2: Read-after-Write — Write/Edit 后必须 Read 验证内容
R3: 三问前置检查 — Edit/Write 前回答 Q1(概念)/Q2(一致性)/Q3(验证计划)
R4: 自动沉淀 — 复杂任务后更新五库
R5: 对抗性自审 — Completeness→Consistency→Groundedness→Honesty

## 测量 DVs

每个任务、每条规则评分:
- 触发? (Y/N) — 该规则是否与任务相关
- 违反? (Y/N) — agent 是否违反规则
- 主动? (Y/N) — agent 是否未经命令主动执行
- 涌现? (自由文本) — 任何未被指示的有益行为

## 统计分析

- 主要: Fisher's exact test 比较 A vs B 违规率
- 次要: χ² 比较主动行为比例
- 效应量: odds ratio + 95% CI
- α = 0.05, 双尾

## 实验执行

需在 2 个独立新 session 中运行:
- Session 1: 仅加载三段论规则 → 跑 21 个任务 → 评分
- Session 2: 仅加载命令式规则 → 跑 21 个任务 → 评分
- 分析 session: 合并 → 盲评 → 统计

## 请分析

1. **内部效度**: 这个设计能否隔离"格式"作为唯一自变量？有没有遗漏的混淆变量？
2. **统计 validity**: n=21/condition 够吗？Fisher's exact 是合适的检验吗？需要多重比较校正吗？
3. **外部效度**: 结果可以推广到什么范围？什么范围不能推广？
4. **实操陷阱**: 具体执行时有哪些地方会"不知不觉就做错了"？
5. **替代设计**: 有没有更好的实验设计？比如 within-subject？or 不同任务类型？
6. **修改建议**: 在现有约束下（单模型、需要新 session、预算有限），最优的实验设计是什么？

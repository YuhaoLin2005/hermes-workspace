# Expert Pool — Sample

> A real example from my pool. Use this format for your own experts.
> Each entry: one person, one principle, one source, one confidence level.

## Engineering

### John Carmack
- **Principle**: "Measure first, optimize second." Don't speculate about performance — profile, then act.
- **Source**: .plan files, QuakeCon keynotes
- **Confidence**: `high`
- **Use for**: Code review, performance investigation, architecture decisions

### Rich Hickey
- **Principle**: *Simple* (objective — one braid, one responsibility) ≠ *Easy* (subjective — familiar, within reach). Prefer simple over easy.
- **Source**: "Simple Made Easy", Strange Loop 2011
- **Confidence**: `high`
- **Use for**: System design, API design, refactoring decisions

## Security

### Ken Thompson
- **Principle**: Validate all input at trust boundaries. You can't trust code you didn't write — including your compiler.
- **Source**: "Reflections on Trusting Trust", 1984 Turing Award Lecture
- **Confidence**: `high`
- **Use for**: Security review, supply chain decisions, input validation

## Design

### Bret Victor
- **Principle**: Creators need immediate, tangible feedback. The gap between action and seeing the result is where ideas die.
- **Source**: "Inventing on Principle", CUSEC 2012
- **Confidence**: `high`
- **Use for**: Tool design, developer experience, internal tool UX

## Writing

### William Zinsser
- **Principle**: "The secret of good writing is to strip every sentence to its cleanest components." Cut words that don't do work.
- **Source**: *On Writing Well*, Chapter 2
- **Confidence**: `high`
- **Use for**: Article drafts, documentation, any prose

## Build Your Own

1. Search: `"[your domain] [skill] philosophy principles"`
2. Read the actual source — talk, book, paper. Not AI summaries.
3. Extract **one principle** you can verify.
4. Confidence-level it. Can you cite the source? → `high`. Consistent but can't pin the quote? → `moderate`. Can't verify? → drop them.
5. Assign them to a scenario from your routing table.

Start with 5-10. My full pool has more across 6 domains — this is the format.
